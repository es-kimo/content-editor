# 테스트 기준

`test-review` 스킬은 이 문서를 일반 기준보다 우선한다.
사람과 에이전트가 같이 고친다. 이슈에 이 문서에 없는 새 기준이 필요하면 그 이슈의 PR에서 함께 고치고 PR 본문 `## 에이전트가 정한 것`에 적는다. 기준을 낮춰 이번 변경을 통과시키는 수정은 리뷰가 막는다.

## 원칙

- 테스트는 **공개 경계에서 관찰 가능한 결과**를 단언한다. 리팩터링으로 깨지면 테스트가 틀린 것이다.
- 테스트 이름은 한국어 동작 문장이다. 파일의 이름만 이어 읽어도 그 모듈이 무엇을 약속하는지 보여야 한다.
- 핵심 흐름 → 경계 입력 → 오류 순서로 쓴다.

## 모듈별 경계

| 모듈                                      | 입력                       | 단언할 것                                                                 | 쓰지 않을 것                             |
| ----------------------------------------- | -------------------------- | ------------------------------------------------------------------------- | ---------------------------------------- |
| `mdx-doc`                                 | 원문 문자열, 픽스처 171편  | 반환값, `printMdx(parseMdx(x)) === x` 같은 왕복 성질                      | 내부 함수                                |
| `editor-config`, `metadata-form`, `sites` | 값                         | 반환값 중 테스트 이름이 말하는 필드                                       | 결과 객체 전체 고정 (필드가 늘면 깨진다) |
| `content`                                 | `fakeGitRepo`·`fakeGitHub` | 가짜 레포의 **최종 상태** (`repo.file`, `repo.log`, `repo.head`)와 반환값 | 요청 URL 목록을 순서대로 고정            |
| `auth`                                    | `mockFetch`, 주입한 `now`  | 응답(상태, 쿠키, 리다이렉트 위치)                                         |                                          |

- API 호출 수가 완료 기준이면 `client.calls`로 **횟수만** 단언한다.
- 사용자에게 보이지 않는 오류 메시지는 단언하지 않는다. `reason`·`kind`로 단언한다.
- 화면 컴포넌트 테스트 환경은 아직 없다. 화면 로직은 `src/lib` 함수로 빼서 테스트한다.

## 도우미

새로 만들기 전에 아래를 쓴다.

| 도우미              | 위치                      | 용도                                                                                 |
| ------------------- | ------------------------- | ------------------------------------------------------------------------------------ |
| `fakeGitRepo`       | `src/test/fake-git.ts`    | 커밋까지 하는 테스트. ref·commit·tree·blob과 폴더 목록을 메모리 레포로 흉내 낸다     |
| `fakeGitHub`        | `src/test/fake-github.ts` | 읽기만 하는 테스트. 트리·GraphQL·contents·blob                                       |
| `mockFetch`, `json` | `src/test/mock-fetch.ts`  | 그 밖의 HTTP. 처리하지 않은 요청은 테스트를 실패시킨다                               |
| `loadFixtures`      | `src/test/fixtures.ts`    | 실제 글 픽스처. 없으면 null이고 `test.skipIf(!fixtures)`로 건너뛴다 (CI는 받아 둔다) |

## 알려진 부채

| 부채                                                                                              | 위치                                                                                                |
| ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |

| `FormField` 5개 전체를 `toEqual`로 고정한다. 필드에 속성 하나만 더해도 깨진다                     | `metadata-form/form.test.ts` "config 순서대로 필드를 만들고…"                                       |

| 가짜 GitHub가 읽기용·쓰기용 두 벌이다                                                             | `src/test/fake-github.ts`, `src/test/fake-git.ts`                                                   |
