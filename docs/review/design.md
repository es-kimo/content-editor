# 화면 기준

디자이너가 없는 프로젝트라 이 문서가 디자인 기준이다. `ui-consistency-review` 스킬은 이 문서를 일반 기준보다 우선한다.
지금 화면(처음, 글 목록, 글 화면)에서 뽑아낸 기준에 [v0.3 PRD](https://github.com/es-kimo/content-editor/wiki/v0.3-PRD) §4·§5의 화면 정책과 [v0.4 PRD](https://github.com/es-kimo/content-editor/wiki/v0.4-PRD) §3·§5의 글 단위 저장·게시 상태·휴지통·자동 보관 정책, [v0.5 PRD](https://github.com/es-kimo/content-editor/wiki/v0.5-PRD) §4·§5의 본문 안 항목 표현을 더했다. 사람과 에이전트가 같이 고친다. 이슈에 이 문서에 없는 새 기준이 필요하면 그 이슈의 PR에서 함께 고치고 PR 본문 `## 에이전트가 정한 것`에 적는다. 기준을 낮춰 이번 변경을 통과시키는 수정은 리뷰가 막는다.

## 원칙

1. **도구다.** 글을 고치고 커밋하는 작업 화면이다. 장식, 그림자, 그라데이션, 애니메이션을 넣지 않는다.
2. **흑백에 의미 색만.** 색은 상태를 알릴 때만 쓴다. 강조는 굵기와 크기로 한다.
3. **글이 먼저다.** 글을 열면 파일 경로가 아니라 제목과 본문이 먼저 보인다. 설정과 기술 정보는 접어 둔다.
4. **원문을 숨기지 않는다.** 일반 편집으로 고칠 수 없는 글은 이유를 보여 주고 원문 편집으로 안내한다. 조용히 빼지 않는다.
5. **입력을 잃지 않는다.** 저장이 실패해도 입력은 남고, 오류는 그 필드 옆에 보인다. 오류와 미저장 표시는 접힌 영역에 가려지지 않는다.

## 토큰

Tailwind 기본 팔레트를 쓰고, 역할마다 값 하나만 쓴다.

| 역할                                    | 값                                                                                          |
| --------------------------------------- | ------------------------------------------------------------------------------------------- |
| 본문                                    | 기본 전경색 (`--foreground`)                                                                |
| 보조 설명, 메타 정보, 로딩              | `text-zinc-500`                                                                             |
| 오류, 권한 없음                         | `text-red-600`                                                                              |
| 경고, 미저장, 폼으로 못 고침, 읽지 못함 | `text-amber-600`                                                                            |
| 성공 (저장함)                           | `text-green-700`                                                                            |
| 주 버튼                                 | 검정 바탕 흰 글자, 다크 모드는 반전. `rounded px-4 py-2`                                    |
| 보조 버튼                               | 테두리만. `rounded border px-4 py-2`                                                        |
| 페이지 셸                               | `mx-auto flex w-full max-w-3xl flex-col gap-6 px-6 py-16`                                   |
| 글자 크기                               | 페이지 제목 `text-2xl font-semibold`, 절 제목 `font-medium`, 본문 `text-sm`, 보조 `text-xs` |
| 간격                                    | 페이지 절 사이 `gap-6`, 절 안 `gap-2`, 라벨과 입력 `gap-1`                                  |

## 글 화면 배치

위에서 아래로 이 순서다. 새 영역을 넣을 때도 제목·본문보다 위에 두지 않는다.

1. **화면 제목**: 저장된 글 제목. 제목이 없으면 ‘제목 없는 글’. 파일 경로를 제목 자리에 쓰지 않는다. 글 목록도 같은 규칙으로 제목을 보인다.
2. **제목 입력**: 편집할 수 있는 글에서만 보인다. 제목·설정·본문·첨부를 함께 저장한다. 입력만으로는 저장하지 않는다.
3. **본문**: 일반 편집 또는 원문 편집. 기본 모드는 글 설정이 정한 대로 둔다. 원문 전용 글이면 본문 위에 제한 이유를 보인다.
4. **글 설정** (기본 접힘): 제목을 뺀 나머지 설정 필드.
5. **기술 상세** (기본 접힘): 파일 경로, blob SHA, 커밋 식별자, API 호출 수·시간, 기술 오류 원문.

### 접힌 영역

- 접힌 영역의 요약 줄에는 영역 이름과 상태가 보인다. 안에 오류가 있으면 오류 색으로, 저장하지 않은 변경이 있으면 미저장 표시를 요약 줄에 둔다. 펼쳐야만 알 수 있는 상태가 없어야 한다.
- 저장하면서 숨겨진 필드에 입력 오류가 나면 그 영역을 펼치고 오류 필드 옆에 메시지를 둔다.
- 사용자가 알아야 할 결과(저장 성공·실패, 충돌, 일반 편집 제한과 그 이유)는 기본 화면에 둔다. 기술 상세에는 그 결과의 기술 원문만 덧붙인다. 기술 상세 내용이 기본 안내를 대신하지 않는다.

### 글 설정 필드

- 설정에 있는 필드·필수 조건·상태 값을 모두 보인다. 알 수 없는 필드나 값도 빼지 않는다.
- 라벨은 설정의 사용자 라벨을 우선한다. 없으면 알려진 필드는 제목·요약·검색어·작성일·상태처럼 쓴다.
- 상태 값은 `ready`를 ‘게시 대상’, `draft`를 ‘초안’으로 보인다. 저장하는 값은 바꾸지 않는다. ‘게시 대상’은 사이트에 반영됐다는 뜻이 아니다.

### 글 상태와 버튼

글 하나를 한 번에 저장한다. 일반 편집에서는 제목·설정·본문·사용 중인 첨부를, 원문 편집에서는 전체 원문과 첨부를 함께 저장한다. 영역마다 따로 저장하는 버튼을 두지 않는다.

- 글 상태는 ‘초안’, ‘게시 대상’, ‘휴지통’ 셋으로 보인다. 휴지통 글은 게시 상태 값과 상관없이 ‘휴지통’으로 보인다. 상태는 화면 제목 가까이 기본 화면에 둔다.
- 버튼은 글 상태에 따라 바뀐다. 한 상태에서 주 버튼은 하나다.

| 글 상태              | 주 버튼     | 보조 버튼                                 |
| -------------------- | ----------- | ----------------------------------------- |
| 초안                 | ‘게시’      | ‘임시저장’, ‘삭제’(확인)                  |
| 게시 대상            | ‘수정 반영’ | ‘게시 내리기’(확인), ‘삭제’(확인)         |
| 휴지통               | ‘복구’      | 없음. 본문 편집은 복구한 뒤에 할 수 있다. |
| 저장한 적 없는 새 글 | ‘게시’      | ‘임시저장’, ‘작성 취소’(확인)             |

- ‘(확인)’ 버튼은 누르면 바로 실행하지 않고 확인 대화상자(`ConfirmDialog`)를 연다. 대화상자에는 대상 글 제목과 결과를 적고, 실행 버튼은 누른 버튼과 같은 이름이다. 처음 초점은 실행하지 않는 쪽에 둔다.
- ‘삭제’는 휴지통으로 옮기는 일이다. 저장한 적 없는 새 글은 휴지통에 갈 것이 없으니 ‘삭제’ 대신 ‘작성 취소’를 쓰고, 확인하면 이 브라우저의 보관본도 지운다.
- 저장하지 않은 변경이 있을 때 ‘게시 내리기’·‘삭제’를 누르면 먼저 반영하거나 버리라고 안내한다.
- 원문에서 상태 값을 바꿔도 ‘임시저장’이 게시가 되지 않는다. 상태는 위 버튼으로만 바뀐다.

### 모드 전환

- 일반 편집과 원문 편집을 오가면 지금 입력을 다른 모드로 이어받는다. 이전 모드에 숨어 있던 입력으로 덮어쓰지 않는다.
- 이어받을 수 없으면(일반 편집이 지원하지 않는 원문, 적용하지 않은 폼, 준비 중인 이미지) 전환을 막고 그 이유를 전환 버튼 가까이에 보인다.
- 전환만으로는 저장하지 않는다.

### 자동 보관 표시

- 브라우저 자동 보관 표시는 저장 상태(미저장·저장함·오류)와 다른 줄에 `text-zinc-500`으로 둔다. 자동 보관은 레포에 저장한 것이 아니므로 성공 색을 쓰지 않는다.
- 자동 보관에 실패하면 같은 줄을 경고 색(`text-amber-600`)으로 바꾼다. 화면 입력은 그대로 둔다.
- 이미지를 뺀 텍스트만 보관했으면 다 보관했다고 표시하지 않는다.
- 다시 열었을 때 보관본이 있으면 본문 위에 보관 시각과 ‘복구’·‘버리기’를 보인다. 복구만으로는 저장하거나 게시하지 않는다. 글이 보관한 뒤 다른 곳에서 바뀌었거나 휴지통에 있으면 바로 덮어쓰지 않고 지금 글과 보관본을 함께 보여 준다.

## 컴포넌트와 상태

- 링크는 밑줄 텍스트다. 버튼처럼 꾸미지 않는다. 예외: 글 분류 탭(`aria-current`로 반전).
- 로딩: `Suspense` fallback `<p className="text-zinc-500">불러오는 중…</p>`.
- 빈 목록: 무엇이 없는지와 조건을 한 문장으로 (`` `<path>`에 맞는 글이 없어요. ``).
- 오류: 무엇이 안 됐는지 + 무엇을 하면 되는지. 예시는 [안내 예시](#안내-예시).
- 로그인이 필요하면 설명 없이 로그인 버튼(`LoginLink`)만 보인다.
- 글 저장 버튼은 글 상태별 이름을 쓴다. [글 상태와 버튼](#글-상태와-버튼) 참고.

## 메뉴와 폼

넣기 메뉴, 넣기·수정 폼, 접힌 영역에 적용한다.

- **키보드**: 마우스 없이 열고, 항목 사이를 옮기고, 고르고, 닫을 수 있다. `Esc`는 메뉴와 폼을 닫는다. 접힌 영역은 `<details>`/`<summary>` 또는 `aria-expanded`가 있는 버튼으로 여닫는다.
- **이름**: 메뉴, 메뉴 항목, 폼, 입력, 아이콘만 있는 버튼은 화면 낭독기가 읽을 이름이 있다. 넣기 메뉴 항목은 ‘이미지’, ‘각주’, ‘각주 출처’, ‘목차’처럼 용도로 부른다. 컴포넌트 이름(`Footnote`, `TOC`)을 이름으로 쓰지 않는다.
- **초점**: 메뉴나 폼을 열면 초점이 그 안 첫 조작 요소로 간다. 적용·취소·`Esc`로 닫으면 연 버튼이나 연 항목으로 초점을 돌린다.
- **적용과 취소**: 폼은 ‘적용’ 때만 본문을 바꾼다. ‘취소’는 아무것도 바꾸지 않는다. 적용하지 않은 폼이 열려 있으면 저장·모드 전환 전에 적용하거나 취소하라고 안내한다.

## 본문 안 항목

일반 편집 본문에 보이는 이미지·각주·출처·자동 목차에 적용한다.

- **표시**: 폼으로 고칠 수 있는 이미지·각주·출처·자동 목차는 컴포넌트 이름과 속성 대신 사진·번호·내용·제목 목록으로 보인다. 사이트 컴포넌트를 실행하지 않는 편집용 표현이므로 사이트 모양과 같다고 안내하지 않는다. 실제 모양은 ‘미리보기’로 본다.
- **이미지**: 사진은 본문 폭을 넘지 않는다(`max-w-full h-auto`). 불러오는 중에는 `text-zinc-500`으로 ‘사진을 불러오는 중…’을, 실패하면 `text-amber-600`으로 ‘사진을 불러오지 못했어요.’와 대체 텍스트, ‘다시 불러오기’ 버튼을 보인다. 대체 텍스트가 비어 있으면 ‘대체 텍스트 없음’을 보인다.
- **각주**: 문장 안 그 자리에 원문의 번호를 위첨자로 보인다. 출처는 ‘출처’, 연결한 각주 번호, 내용을 한 블록으로 보인다. 번호는 원문 값 그대로 보이고 순서대로 다시 매기지 않는다.
- **목차**: ‘목차’와 본문 소제목(`##` 이하) 목록을 깊이대로 들여 보인다. 소제목이 없으면 ‘글에 제목을 추가하면 목차가 채워져요.’를 보인다.
- **선택**: 항목은 클릭·탭·`Enter`·`Space`로 고른다. 고르면 항목 바로 아래에 조작 버튼을 보인다. 이미지는 ‘수정’(대체 텍스트)·‘교체’·‘제거’·‘앞으로’·‘뒤로’, 각주·출처는 ‘수정’, 목차는 ‘제거’다. 버튼 이름은 ‘삽입 항목’ 목록과 같게 쓴다. 마우스를 올려야만 보이는 조작을 두지 않는다.
- **초점**: 폼을 적용·취소·`Esc`로 닫으면 고른 항목으로 초점을 돌린다. 항목을 제거했으면 바로 앞 블록으로, 앞 블록이 없으면 본문 처음으로 돌린다.
- **고칠 수 없는 항목**: 지금처럼 이름과 속성을 보이고 `text-amber-600`으로 이유와 원문 편집 안내를 붙인다. 빈칸으로 숨기지 않는다.
- **좁은 화면**: 폭 360px에서 사진·목차·조작 버튼이 가로로 넘치지 않는다. 버튼은 줄을 바꾼다.
- **삽입 항목 목록**: ‘삽입 항목’ 목록은 그대로 둔다. 본문 안 표시는 같은 조작으로 들어가는 진입점을 하나 더 두는 것이다.

## 좁은 화면

- 화면은 한 열이다. 보조 영역(글 설정, 기술 상세, 미리보기, 삽입 항목 목록)을 본문 옆에 둔 화면이라도 좁은 화면에서는 본문 다음으로 내린다.
- 원문 코드 영역 외에는 가로 스크롤 없이 주요 작업(글 열기, 설정 수정, 넣기, 재편집, 저장)을 할 수 있다. 긴 파일 경로·SHA·URL은 줄을 바꾼다(`break-all`).
- 폭 360px 화면에서 가로 넘침이 없는지 확인한다.

## 문구

화면에 보이는 안내, 버튼, 라벨, 오류에 적용한다. 코드 주석, 테스트 이름, 이 문서 같은 개발 문서와 글 본문 자체의 말투는 대상이 아니다.

- 해요체로 쓴다: “저장했어요”, “글을 찾을 수 없어요.” 부탁은 “~해 주세요”로 쓴다. 해라체·합쇼체를 섞지 않는다.
- 안내는 사용자가 할 행동으로 끝낸다. 개발 용어(config, metadata, blob, WYSIWYG, import)를 기본 안내에 쓰지 않는다.
- 버튼은 짧은 행동 이름이다: ‘임시저장’, ‘게시’, ‘수정 반영’, ‘넣기’, ‘적용’, ‘취소’. 저장 범위(‘본문 저장’, ‘글 설정 저장’)를 이름에 붙이지 않는다.
- 같은 대상은 같은 이름으로 부른다.

| 쓰는 말   | 쓰지 않는 말         |
| --------- | -------------------- |
| 글        | 포스트               |
| 글 설정   | metadata, 메타데이터 |
| 일반 편집 | WYSIWYG              |
| 원문 편집 | source, 원문 모드    |
| 글 분류   | 컬렉션, collection   |
| 레포      | 저장소               |

### 안내 예시

저장 성공과 사이트 반영은 다른 일이다. 저장 성공만으로 게시나 반영이 끝났다고 말하지 않는다.

| 상황                    | 안내                                                                                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 임시저장 성공           | 임시저장했어요. 게시하기 전에는 사이트에 보이지 않아요.                                                                                           |
| 게시·수정 반영 성공     | 게시 대상으로 저장했어요. 사이트에 반영되기까지 시간이 걸릴 수 있어요.                                                                            |
| 게시 내리기 확인        | 게시를 내리면 초안이 돼요. 사이트에서 사라지기까지 시간이 걸릴 수 있어요.                                                                         |
| 게시 내리기 성공        | 초안으로 바꿨어요. 사이트에서 사라지기까지 시간이 걸릴 수 있어요.                                                                                 |
| 삭제 확인               | ‘<제목>’을 휴지통으로 옮길까요? 휴지통에서 초안으로 복구할 수 있어요. 첨부 이미지는 지우지 않아요. 사이트에서 사라지기까지 시간이 걸릴 수 있어요. |
| 삭제 성공               | 휴지통으로 옮겼어요. 휴지통에서 초안으로 복구할 수 있어요.                                                                                        |
| 작성 취소 확인          | 작성을 취소할까요? 이 브라우저에 보관한 입력도 지워져요.                                                                                          |
| 복구 성공               | 초안으로 복구했어요. 게시하려면 ‘게시’를 눌러 주세요.                                                                                             |
| 자동 보관 성공          | 이 브라우저에 보관했어요 · <시각>                                                                                                                 |
| 자동 보관 실패          | 자동 보관하지 못했어요. 저장하기 전에는 이 화면을 닫지 마세요.                                                                                    |
| 이미지 빼고 보관        | 이미지 <n>개는 보관하지 못했어요. 복구한 뒤 이미지를 다시 골라 주세요.                                                                            |
| 보관본 복구 안내        | <시각>에 이 브라우저에 보관한 입력이 있어요. + ‘복구’·‘버리기’ + 다른 기기나 다른 브라우저, 브라우저 데이터를 지운 뒤에는 복구할 수 없어요.       |
| 변경 없음               | 변경된 내용이 없어요.                                                                                                                             |
| 입력 오류               | 필드 옆에: 제목을 입력해 주세요.                                                                                                                  |
| 충돌                    | 글을 연 뒤 다른 곳에서 글이 바뀌었어요. 입력한 내용을 따로 보관한 뒤 글을 다시 열어 주세요.                                                       |
| 원문 전용 글            | 이 글은 일반 편집을 지원하지 않아요. 원문 편집을 이용해 주세요. + 구체적인 제한 이유                                                              |
| 미저장 변경             | 저장하지 않은 변경이 있어요. 바뀐 곳: 본문, 글 설정                                                                                               |
| 적용하지 않은 폼        | 열려 있는 폼을 먼저 적용하거나 취소해 주세요.                                                                                                     |
| 목차를 채울 제목 없음   | 글에 제목을 추가하면 목차가 채워져요.                                                                                                             |
| 사진 불러오기 실패      | 사진을 불러오지 못했어요. 다시 불러오거나 이미지를 교체해 주세요.                                                                                 |
| 복구한 글의 빠진 이미지 | 이 이미지는 보관하지 못했어요. 이미지를 다시 골라 주세요.                                                                                         |

오류 응답 원문이나 커밋 식별자는 기본 안내를 대신하지 않는다. 필요하면 기술 상세에 둔다.
